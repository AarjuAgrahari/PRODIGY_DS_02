# Prodigy Task 2 — Titanic EDA Project

## Dataset

Train data used for EDA:
https://raw.githubusercontent.com/dsindy/kaggle-titanic/master/data/train.csv
This project performs data cleaning and exploratory data analysis (EDA)
on the Titanic dataset.

## Dataset
The dataset used is `train.csv` from the Titanic Kaggle competition.

Columns include:
PassengerId, Survived, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, Embarked

## What I did
- Loaded and inspected the data
- Handled missing values
- Removed unnecessary columns
- Visualized distributions (Age, Fare, Class)
- Explored relationships such as:
  - Survival vs Gender
  - Survival vs Class
  - Fare vs Survival

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Key Insights
- Females had a higher survival rate
- 1st class passengers survived more often
- Higher ticket fares were linked with higher survival
